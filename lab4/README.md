### Лабораторна №4

### Інструкція запуску

```
   git clone https://github.com/alinakarpenkReactNativeLabs.git
   npm install
   npm start
   npx expo start

```

### Короткий опис функціоналу

* `Навігація:` перегляд структури папок у пам'яті пристрою з можливістю переходу між рівнями («вгору» та «вглиб»).

* `Управління:` файлами: створення нових папок та текстових файлів (.txt), а також їх видалення.

* `Редагування:` відкриття та редагування вмісту текстових файлів через окремий екран.

* `Відображення даних:` перегляд властивостей файлів (розмір, дата зміни) та загальна статистика використання пам'яті пристрою

* `Інтерфейс:` адаптивний дизайн за допомогою styled-components з візуальними підказками (іконки, модальні вікна, breadcrumbs)
